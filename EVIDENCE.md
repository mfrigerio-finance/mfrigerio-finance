# Capability Evidence Matrix

This page maps professional capability claims to the type of evidence available publicly while respecting confidentiality obligations.

The purpose is to keep four things distinct:

1. **documented outcomes**;
2. **professional delivery scope**;
3. **platform exposure or participation**;
4. **sanitised methods and architecture evidence**.

## Evidence classification

### Documented professional outcome
A measurable result from professional delivery that can be stated publicly without exposing confidential client information.

### Professional delivery scope
Responsibilities, methods or outputs represented in professional CV and portfolio material. This indicates work performed in the area, not necessarily sole ownership of every adjacent activity.

### Platform landscape
A platform or environment represented in professional materials. Exposure may range from direct hands-on work to cross-functional transformation participation depending on the mandate.

### Sanitised case study
A de-identified description of a professional problem, approach, controls and outcome/value. Client-specific data and proprietary implementation detail are intentionally removed.

### Architecture evidence
A public description of the principles used to structure finance, data, process and system decisions. It demonstrates reasoning and control philosophy rather than exposing client source code.

## Ownership discipline

A technology, accounting framework or platform appearing in this repository should **not** automatically be interpreted as a claim of sole end-to-end production ownership.

The profile intentionally distinguishes:

- direct professional delivery;
- cross-functional participation;
- platform exposure;
- architecture or methodological capability;
- documented measurable outcome.

This distinction is deliberate. The goal is to make the profile useful for hiring decisions without inflating scope beyond what can be supported.
